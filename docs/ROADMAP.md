# Navy Thunder Release Roadmap v2

> **终点重定义**：本路线图的终点不再是"当前技术缺口补完"，而是 **Navy Thunder 1.0 正式发布**——
> 一款机制完整、内容完整、AI 完整、UI 完整、性能稳定、新玩家可直接安装游玩的单机海战游戏。
> 每完成一个阶段重新做一次 Release Gap 检查；只有 Release Gate 全部满足才算完成。

基线：commit `301ea58`，Phase 0–7 完成（93 测试全绿，校准 12/12，32 艘舰数据，4 个引擎测试用阵营数据文件）。

## 0. 发布范围决策（1.0 定义）

| 决策 | 结论 | 依据 |
|---|---|---|
| 游戏形态 | **单机海战遭遇战**（PvE）：玩家操舰 + AI 友军/敌军；附全 AI 观战模式与靶场 | 核心资产（确定性战斗引擎、舰船数据）直接支撑；范围可控 |
| 时代/阵营 | 二战为主；首发阵营 **美/日/英/德** | 数据集与校准全部基于该时代；四国舰船/武器史实资料最全 |
| 战斗规模 | 3v3 ～ 6v6 舰船 + 舰载机小队 | 引擎性能与 AI 复杂度的现实平衡 |
| 多人 | **Release 前无需**。理由：确定性 tick + 事件日志已是 lockstep 就绪形态，但网络栈是独立大工程；单机 PvE 已构成完整游戏。列入 Post-Release | — |
| 前端引擎 | **Godot 4 (.NET/C#)**。理由：可自主安装（无许可/体积负担）、C# 直接复用 Core（multi-target）、glTF 导入完善。Unity 未安装（备选，Core 零依赖可迁移） | 本机审计 2026-09-19 |
| 资源来源 | **War Thunder 客户端提取**（用户已声明获得许可，授权假设记录于 R5.3）：舰船模型/音效从 aces/char.vromfs 提取转换；特效用 Godot 粒子自制；UI 自制 | D:\WarThunder 在位（aces/char.vromfs.bin 已确认） |
| 语言 | 简体中文 + 英文 | 开发者与目标玩家 |

## 2. Navy Thunder 1.0 Release Gate（全部满足才发布）

1. **玩法闭环**：从主菜单 → 选舰 → 进入战斗 → 完整打一场 → 战斗结束 → 战报，全程无需开发者干预
2. **机制完整**：R0 全部任务验收通过（舰炮/弹药/装填/瞄准/弹道/穿深/损伤/破片/爆炸/起火/进水/损管/TDS/沉没/飞机/防空/炸弹/鱼雷/胜负/战报）
3. **AI 完整**：R1 验收——全 AI 对战从启动到战报无人干预，行为通过场景级测试（非单元测试）
4. **内容完整**：≥15 可玩舰船（精修布局）、≥8 可选玩家舰、≥10 机型、四阵营
5. **数据完整**：全部数据过 schema 校验；无 Tier-3 占位数据参与战斗；校准报告达标
6. **资源完整**：参战舰船均有模型/贴图；武器音效、命中/爆炸/火灾/进水特效齐备；音乐与环境音
7. **UI 完整**：主菜单/选舰/设置（图像/音量/键位）/HUD/损伤面板/战斗结束/战报/教程提示
8. **性能达标**：预算内（R4.1）连续 2 小时运行无泄漏、无崩溃
9. **工程质量**：CI 全绿（含校准报告门槛）；无关键 TODO/placeholder/测试专用接线
10. **发布工程**：Release Build 从干净环境安装可玩；版本/存档/配置/日志齐备；第三方与资源授权审计完成
