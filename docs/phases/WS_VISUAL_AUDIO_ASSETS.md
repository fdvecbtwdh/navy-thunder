# WS — 视觉与音频资产工作流（Visual & Audio Assets）

> 状态：`[ACTIVE 2026-10-05 立项]`——与 Phase 06/07 并行运行，产物汇入 Phase 08 产品化验收。
> 定位：2026-10-05 全仓现状核查确认，"视觉与音频与玩法核心的差距"是当前玩家体验的最大短板。本工作流把资产缺口按**玩家体验优先级**排布（直接影响观感与核心战斗体验的先行，装饰性环境靠后），**不是**统一堆到最后的打磨项。
> 原则：已完成的 Phase 00–05 历史不回填；Phase 03 遗留项（P03-2 贴图、P03-5 击毁态等）的**承接去向由本文档正式接管**（见 PHASE_03 §14 增补注记）。
> 资产来源策略：**优先复用已打通的 War Thunder 提取/转换管线**，不重新发明资产管线（见 §3）。

## 1. 基线（2026-10-05 实测）

**已有**：23/30 舰真实模型（4 级 LOD + nodeMap 炮塔挂点，GLB 由自有客户端转换，不入库）；模型几何解码错误已修复（P03.2，23 舰×4 级约 3800 万索引零违规 + 8 舰侧影核对）；程序化船体保底轨在役；图形 HUD/损伤/损管面板完整；命中反馈五态图标；粒子火/烟锚定真实部件；事件驱动音频播放机制（三路音量总线）。

**缺失/占位**：全部模型无贴图（纯灰材质）；无击毁态破损模型；炮塔仅偏航无俯仰动画，副炮/防空静态；特效为发光渐隐球；海面为平面色块；岛屿为圆柱占位；飞机为体块占位；音效全部程序合成；无音乐/UI 音。

## 3. 里程碑

### VA-1 舰船模型几何质量回归门 —— 已完成 + 常态化

P03.2（2026-10-05）已修复全舰队几何爆炸（顶点布局 storageFormat 表驱动 + packed IB 块边界），本里程碑把修复成果固化为**每艘新转换舰的强制验收**：

- 转换器对每舰输出几何完整性报告：索引窗口违规数必须为 0；
- 新增舰船入队流程：光栅三视图侧影人工核对 + GUI 实模型截图各留档一张；
- 资产一致性测试扩展：校验 convert_report 中零违规字段，违规即 CI 红。

**验收标准**：任一艘使用真实模型进入 GUI 战斗的舰船，不出现跨区域巨大拉伸三角形、顶点爆炸、异常尖刺或错误模块连接；几何检查进入 CI 自动门禁。

### VA-2 贴图与材质管线 —— 最高优先（直接决定观感）

dynModelDesc.bin 解析 → tex 路径 → dxp→dds/png 解码 → glTF 材质接入；无贴图舰回退纯色（保留现行为）。灰模到"有皮肤的船"是当前观感提升最大单项。

**验收标准**：指定三舰（俾斯麦/弗莱彻/长门）在 GUI 战斗中具备漫反射贴图的完整可用材质，不再以纯灰色占位材质作为最终表现；贴图加载不突破内存与加载时间预算（联动 P08-1）。

### VA-3 击毁态模型与损伤外观

验证 `*_dmg` v6 头差异 → 重损/击沉时替换或叠加破损网格，接入现有沉没姿态插值；若 v6 解析成本超预期，降级方案=程序化破损（黑烟+局部隐藏+倾角加大的沉没姿态）。

**验收标准**：被击沉的舰船以破损外观下沉（而非完整外形渐隐）；重损舰（≥2 段丧失）有可见的持续损伤标记。

### VA-4 炮塔俯仰与武器视觉

炮管俯仰随火控仰角（Core 需暴露俯仰只读量，语义与偏航一致）；副炮/防空炮至少做到挂点摆放与随动旋转（可低频更新）。

**验收标准**：主炮炮管俯仰角与火控解算一致可见；副炮/防空炮不再静止穿模。

### VA-5 特效升级（分两档）

- **核心战斗档（先行）**：炮口焰粒子化、命中水柱按弹径分级、殉爆火球、持续油火；
- **氛围档（后置）**：近失弹水帘、破片水线、沉没漩涡气泡。

**验收标准**：炮击/命中/殉爆三类事件不再以发光球体作为最终表现；特效池在 6v6 战斗内不突破帧预算。

### VA-6 海面 / 环境 / 天空

Godot 着色器视觉级波浪（Gerstner，纯表现、与模拟零耦合——PROJECT_DESIGN §8.1 裁决）；岛屿替换为程序化低模（数据驱动坐标）；天空/光照按阵营/时段做 2-3 套预设。

**验收标准**：海面具备波浪起伏与岸线/远处渐变的基本视觉层次，不再是平面色块；岛屿具备可辨识的岛形轮廓；6v6 帧率不回归。

### VA-7 音频资产（正式开发项）

两步走：① 研究 WT 音频库（FMOD/FEV bank）解析可行性——可行则按 LICENSE_AUDIT 边界走"用户自有客户端重建"路线；不可行或成本过高则改用自有录制/自由授权素材。② 按事件清单补齐资产：主炮（按口径分档）/副炮/防空炮/命中装甲/命中水面/爆炸/殉爆/鱼雷发射与命中/飞机引擎/火灾/进水警报/损管/沉没/海浪环境/UI/音乐。

**验收标准**：主炮、命中、爆炸、鱼雷等核心战斗事件使用最终或接近最终的真实音效资产（不再是程序合成占位音）；环境音与至少一套战斗音乐到位；音量分级（主/效果/环境）继续生效。

### VA-8 图像质量分级

按 P08 联动：LOD 距离/粒子密度/分辨率缩放/海面质量分 3 档预设，接设置界面。

**验收标准**：设置界面可选低/中/高画质并在重启后保留；低档在集成显卡达到可玩帧率。

## 4. 顺序与依赖

```text
VA-1（已完成，常态化）
VA-2 贴图材质 ──┐
VA-7 音频（核心战斗音先行） ──┼── 立即并行启动（直接影响当前观感/听感）
VA-4 炮塔俯仰 ──┘
VA-3 击毁态 → VA-5 特效 → VA-6 海面环境 → VA-8 画质分级（Phase 08 收口）
```

- VA-2 依赖 dxp 解码研究（参照 wt-tools）；VA-3 依赖 v6 头验证；VA-4 需 Core 暴露俯仰只读量（小改动，走 P04 尾或随 VA-4）。
- 与 Phase 08 关系：VA-8 与性能门禁（P08-1）联合验收；全部 VA 项的产物在 P08-6 打包审计时复核许可边界。
