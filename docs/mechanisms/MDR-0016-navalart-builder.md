# MDR-0016: NavalArt 建造 / 物理（设计侧基准）

- 状态: 已决议
- 置信度: **高**（官方公告与商店页一手证据）
- 参考优先级: **NavalArt**（舰船设计、建造、部件、沙盒）

## 平台事实（确凿）

**Steam 游戏**（App 842780，store.steampowered.com/app/842780/NavalArt/），开发者 Rigidbody、发行商 RZ Entertainment，2018-06-20 EA，Unity 引擎 + Mirror 网络库。2026-09 处于 1.53 正式 / 1.6 公测。**非 Roblox 游戏**（部分搜索摘要误传，已用一手证据排除）。

## 建造体系（采用方向）

- **可调模块 + 顶点编辑双层**：可调模块（Length/Height/ForwardWidth/BackwardWidth/TopRoundness/BottomRoundness/Spread…，米制，0.05m 级刻度）拼船体；V1.1（2025-03）顶点编辑船体（顶点吸附/世界坐标/分段拆分）作为进阶自由度。
- **装甲**：按块赋 mm 值；**重量按块的体积而非表面积**计算（厚块埋入船体减重是社区技巧）；斜面部件独立存在。差异化机会：逐面装甲（舷侧/甲板分厚）是 NavalArt 社区痛点。
- **部件清单（照抄其广度）**：分档马力主机、螺旋桨/舵、容积泵、预设口径炮塔（可调俯仰方位死区、Ripple Firing、扬弹机独立部件）、AA 点射模型、VLS/CIWS/诱饵、雷达+测距仪+火控部件（英/美/苏/意史实型号）、机库/升降机/弹射器航母系统、直升机平台。
- **射界 3D 编辑器**（1.6 公测：射击弧线/仰角批量编辑）值得同步。

## 物理体系（采用方向）

- **体积排水浮力**：排水体积 vs 总重定吃水；重量/重心参与计算；波浪实时物理（V1.0，2024-11-27）；1.53 加浮心(CoB)指示器、水线/纵倾优化。
- **物理沉没**：毁伤→浮力损失/重心破坏→下沉，无"血条扣完即沉"；容积泵排水。**Navy Thunder 的浮力求解器以 NavalArt 理念为设计基准，战斗判定叠加 WT 规则（浮力≥100%、丧失不沉性等，见 MDR-0007/0008）。**
- 教训规避：早期排水量虚高 50–90% 被攻略吐槽 → 排水量显示从第一天做对；CG/CoB 指示尽早提供（NavalArt 1.53 才补齐，属可抢跑点）。

## 伤害模型（仅参考）

V1.52（2026-09-02）重做：部件 HP+全船耐久池双轨、爆炸逐层装甲衰减+免疫阈值、鱼雷 TDS=距离+薄板组合、爆炸半径-伤害平方关系（V1.1）、AP 引信灵敏度式过穿（社区实测）。战斗数值不采用；"逐层衰减+免疫阈值"思想进 MDR-0005 备选实现。

## 版本历史（官方公告核实）

0.1 动力/天气 → 0.3 伤害/物理/火效 → V1.0（2024-11-27）航母系统+导弹重做+HE/AP 分列 → V1.1（2025-03）顶点编辑+多国雷达 → 1.41（2026-03）弹道/音效重做 → **1.52（2026-09-02）伤害模型重做** → 1.53（2026-09-09）ModTool（穿深修正/弹重/AA 伤害类型）+Port → 1.6 公测（射界编辑器/荷兰籍/弹药库殉爆战役修正；预告潜艇与反潜）。

## 实现与替换方案

- 舰船数据模型（Phase 3 起）按"可调模块+块状装甲+部件清单"组织（`data/ships/`）；后续建造器 UI（Unity 前端阶段）直接复用该数据模型。
- ModTool 等价物（模组部件）在数据 schema 中预留 `modOrigin` 字段。
