# MDR-0009: 损管（Damage Control）

- 状态: 已决议（框架高置信；数值中等）
- 参考优先级: War Thunder（战斗计算）

## 决议

**双轨制**（WT 官方自己因社区压力做的并存设计，直接照抄）：

- **新系统（默认，Spearhead 模型）**：修理 Repair / 灭火 Extinguishing / 抽水 Unwatering 三流程**全自动同时进行**；玩家预设优先级顺序；模块修理/推进修复完全自动（"只要还有船员资源就修"）。每舰 **DC 系数** = f(船体尺寸, 员额, 舰船代数 generation)，降低第二/第三流程的时间惩罚（幅度不大）。
- **旧系统（开关选项）**：手动三动作（灭火/堵漏+抽水/模块修理），各自耗时受技能/员额影响，可中途取消（~3s），同时开启互相拖慢。
- 硬规则：模式切换 4s；**海战禁用野战修理**（螺旋桨轴/轮机舱/锅炉房自动修理移除）；堵漏完成后才显示抽水图标（先堵后抽）。
- 乘员不足（< 修理阈值）时任何损管不可用。

## WT 行为与证据

- 官方 dev blog《The New Damage Control Mechanic for Naval》（2025-11-05）+ 2.51 Spearhead changelog（2025-11-11）。
- 回退开关：2025-11-07 官方置顶管理员评论确认。
- 社区 dev server 实测（2025-10）：取消 ~3s、每类 ~30s 冷却、灭火时修理倍率 1.0→1.45（官方未全确认 → 数值进 calibration）。

## 历史变化

- →2025-11-11 旧手动系统；2.51 起新系统默认+旧系统开关。**引用 2025 年前的损管文章需注意已不是默认行为。**
- 旧系统时代"故意不修黑舱省船员"漏洞被新系统移除（官方承认）。

## 未知点

DC 系数公式与"舰船代数"定义；冷却/倍率的官方数值。

## 实现与替换方案

- Phase 3：`DamageControlSystem`（三流程调度器 + `DcMode { Automatic, Manual }` + 优先级配置 + DcCoefficient）。
- 全部时长/冷却/倍率进 calibration；AI 舰与玩家舰的灭火速度差异做成显式可调参数（WT 现状 AI 2–3s / 玩家 ≥10s 被当 bug 抱怨，**不照抄不一致性**）。
