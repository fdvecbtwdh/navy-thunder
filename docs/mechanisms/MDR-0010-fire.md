# MDR-0010: 火灾

- 状态: 已决议（规则高置信；数值未公开）
- 参考优先级: War Thunder（战斗计算）

## 决议

- **起火 = 独立掷骰**：与舱室剩余 HP 无关（官方明文"起火概率不取决于损伤程度"）；按被伤模块/舱室 × 弹种 roll。舱室"高度易燃"；发动机按类型；油箱按弹种（外置油箱更危险）。
- **火种实体**：统一 fire 实体，位置/宿主决定后果（官方无"燃油火/弹药火"三分类的机制文本，仅视觉区分）。
- **蔓延**：火可从炮塔沿弹药电梯**自顶向底**蔓延至弹药库（仅大型主口径电梯；2.47 Leviathans）；从底部点燃几乎无预警。社区实测炮塔火 2–3s 可烧到弹药库。
- **后果**：火烧舱内乘员；弹药库受火 → 概率殉爆（Ammo Wetting 减免，见 MDR-0011）。
- **扑灭**：损管灭火流程（MDR-0009）；进水淹灭火焰。
- **数值**：燃烧 DPS、自然熄灭时长官方未公开 → 全参数化（AI 与玩家灭火速度差异不照抄）。

## WT 行为与证据

- 官方 wiki（HE/超压文 + Ship Modules）：起火 roll、易燃性、按弹种。
- 2.47 Leviathans changelog：电梯火自顶向底蔓延、Ammo Wetting 仍有效。
- Seek & Destroy（2024-06）：弹药库起火语音警报 + 按钮高亮。

## 历史变化

- 旧系统手动灭火键（FPE 式全船灭火）→ 2.51 并入自动损管 Extinguishing 流程。
- 2.47 修复部分战列舰（Kirishima 等）电梯不能起火的 bug。
