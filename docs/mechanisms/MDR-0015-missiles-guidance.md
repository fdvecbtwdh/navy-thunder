# MDR-0015: 导弹与现代扩展层

- 状态: 已决议（架构级）
- 置信度: 中高
- 参考优先级: War Thunder（战斗计算）

## 决议

**导弹是与炮弹弹道完全解耦的独立制导层**（WT 即如此：海军导弹刻意限制在低级试验性内容，但引擎抽象独立）。

组成：
- **推进段**：助推/续航推力曲线、燃尽质量变化（走 `IDragModel` 同一弹道积分）。
- **导引抽象 `IGuidance`**：
  - **IR**：被动导引头（FOV/增益/离轴角/烧穿距离）；flare 与 IRCCM 反制——IRCCM 实现为策略枚举（FOV 收窄/导引头关机再捕获/上升时间检测/空间分辨）。
  - **SARH**：弹上被动接收载机持续照射回波；载机失锁即失效。
  - **ARH**：弹载主动雷达；中段 IOG 惯性 + 数据链修正 + 末段开机自主。
- **雷达锁定状态机**：soft lock（TWS 边扫边跟）/ hard lock（STT）；锁定质量影响 SARH 允许发射与导引精度（AESA 例外可两档并行）。
- **对抗**：chaff（假雷达源，对老雷达/半主动有效）、flare（热诱骗，对早期 IR 弹 4–6 发即可诱离、对现代弹几乎无效）、RWR 告警事件流。
- **引信**：导弹近炸引信（雷达/激光，radius+armDistance，同 MDR-0003 抽象）。
- **载台**：VLS（垂直发射）、CIWS、空射反舰（掠海+主动末段）。

## WT 行为与证据

- 官方 wiki：《Infrared Missiles》（2019-11）、《IRCM》（2025-09 更新）、《SARH 开发文》（2020-09）。
