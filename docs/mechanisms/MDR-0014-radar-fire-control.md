# MDR-0014: 雷达 / 火控 / 防空

- 状态: 已决议
- 置信度: 中高（交互层公开；算法层未知）
- 参考优先级: War Thunder（战斗计算）

## 决议

- **火控分层**：自动解算档（Arcade 式：自动测距+试射收敛"三轮修正"）与手动档（RB 式：测距手带误差、看水柱手修、目标远近变化不自动更新）两档，作为火控模式配置。
- **雷达模块**：火控挂接雷达/电探；**被毁 → 散布增大、丢失弹道修正、炮塔转本地独立控制**。雷达提供对空/对海锁定点。
- **提前量**：FCS 解算输出红色提前量箭头；机动显著降低双方精度。
- **AI 炮组**：副炮/AA 自动开火但目标选择保持**粗糙**（玩家只能粗略指定）——这是 WT 可玩性来源之一，不做过精的 AI。
- **防空**：大中口径 AA 用 VT 弹（MDR-0003）；空爆后按标准破片锥结算；AA 射速/引燃按部件数据。
- **散布**：椭圆散布（水平+纵向）按炮种数据驱动，与弹道解耦（WT 2025-2026 反复调它 → 必须独立可调）。

## WT 行为与证据

- 2017 官方《Naval Test: New aiming system, hydrodynamics》（瞄准/水柱/横摇基础）。
- 官方 wiki Ship Modules：火控室/雷达损毁效果。
- 2025-03 Arcade 改版：AI 炮手可自动开主炮（争议，作为可选配置）。
- 注意：论坛《Naval Aiming Rework》（2025-12 起）是**玩家建议帖**，非官方实装——勿混淆。

## 未知点

FCS 解算误差模型；雷达精度对提前量的数值影响；AI 防空开火距离/命中率参数；散布公式。

- 雷达损毁 → `DispersionPenalty` 事件链，测试断言散布可测增大。
