# MDR-0007: 船体分区与丧失不沉性

- 状态: 已决议
- 置信度: **高**
- 参考优先级: War Thunder（战斗计算）

## 决议

- 每舰若干 hull sections（段），每段独立 HP（结构层，与舱室乘员层分离——WT 2025-03 后的双层架构）。
- **小/中型艇**：任意一段被打掉即沉；单段承伤 ≥ 全部段之和同样致死。
- **护卫舰及以上**：**中段 ≥2 段完全摧毁** → 触发"丧失不沉性"（loss of unsinkability）：即使装甲未被击穿也自行生成破口并持续进水直到沉没，**进水不可逆**。首尾段不计入。
- 未穿甲命中在表面产生结构伤害，可累积打黑船体段。

## WT 行为与证据

- 2.45 Hornet's Sting（2025-03-18）changelog："船体强度回归、扩展并重新设计"+丧失不沉性取代旧 hull break；dev server 机制描述（论坛 2025-02 反馈帖）。
- 2.47 Leviathans（2025-06-25）：修正破口生成（动能破口仅来自最大口径弹；爆炸破口尺寸∝爆压）；炮弹破口修补 5–20s。
- wiki 舰船页：Renown "Number of sections 10"。

## 历史变化

- 2018-10（1.83）海战 OBT：舱室+进水简化模型 → 约 2023 短暂存在"不可修补破口" → 2025-03 现行分段+丧失不沉性。**引用旧资料（2023-2024）描述 hull break 的内容一律过时。**

## 未知点

每段 HP 数值（逐舰，游戏文件内）；HE/动能对"段摧毁"判定的伤害换算权重。

## 实现与替换方案

- Phase 3：`HullSection { Hp, Role(Bow/Mid/Stern), Destroyed }` + `UnsinkabilityChecker`（中段≥2 或小艇任一段）。
- 段 HP 按舰级参数化进舰船数据；校准以"击沉所需主炮弹数"行为锚点对表。
