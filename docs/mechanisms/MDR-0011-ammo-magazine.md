# MDR-0011: 弹药存储 / 一级弹药 / 殉爆

- 状态: 已决议
- 置信度: **高**
- 参考优先级: War Thunder（战斗计算）

## 决议

- **两级弹药**：每门炮有一级弹药（ready-use lockers，位于炮塔/输弹通道）——用一级弹时装填速度最高；打空后从主弹药库补给，补给 **~30–40s**（`wt_reference/first_stage_resupply_s=35`，社区实测）且**开火时暂停**；补给期间射速大幅下降。
- **一级弹药架被击中会殉爆**；炸毁后该炮塔只能低效装填。
- **弹药库（magazine）**：非线性模块（无渐进损伤）；**被摧毁"通常会殉爆"**；**殉爆威力与剩余弹药量成正比**（Leviathans：按剩余弹丸/药包计算爆炸力）。水下殉爆效果 2.54.0.38（2025）补丁加入。
- **火→弹药库通道**：炮塔火沿电梯蔓延至弹药库按概率殉爆；**Ammo Wetting** 改装降低火灾引爆炸药概率。
- **耗尽**：主库打空 = 真耗尽；Leviathans 起显示"无法开火"图标。

## WT 行为与证据

- 论坛实测（2023-07）：补给 ~35s 开火暂停；2024-12 论坛："一级弹药架机制毁游戏"（殉爆+低效装填描述）。
- 2.47 Leviathans changelog：殉爆威力∝剩余弹药量、Ammo Wetting 有效、"弹药耗尽无法开火"图标。
- Viking Fury changelog（2020-03）：存在"取消一级弹药舱改弹药库直供"的舰种差异（数据字段，非全舰统一）。

## 历史变化

- 一级弹药至少 2020-03 已存在（推断与地面载具 2018 "First-order ammo racks" 同引擎同期体系）。
- 2.51 Spearhead 给街机模式鱼雷管加独立弹药补给。

## 未知点

逐舰一级弹药容量；补给时长精确公式；殉爆概率基数与 Ammo Wetting 减免 %；"通常殉爆"的非殉爆分支条件。

## 实现与替换方案

- Phase 3：`AmmunitionSystem`（magazine + per-turret ready rack + resupply 状态机）+ `DetonationSystem`（剩余弹药量→爆炸规模）。
- 容量/时长/概率进舰船数据与 calibration。
