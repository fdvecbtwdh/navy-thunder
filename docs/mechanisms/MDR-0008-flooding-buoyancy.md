# MDR-0008: 进水 / 浮力 / 沉没

- 状态: 已决议
- 置信度: **高**（框架）；数值公式未公开
- 参考优先级: War Thunder（战斗计算）+ NavalArt（物理沉没理念）

## 决议

- **破口产生**：动能击穿在水线附近成口（**仅最大口径弹**的动能破口进水——Leviathans 规则）；爆炸破口尺寸∝爆压；鱼雷破口最大（修补最久）；丧失不沉性后自动生成破口。
- **进水条件**：只有**位于水下**的破口进水；水上破口先记录，舰体横倾/下沉使其入水后激活。
- **泵**：实体模块，损坏降排水速度；改装 "New Pumps" 提升。
- **后果链**：各舱浮力损失百分比合计 **≥100% → 沉没**；不对称进水 → **可见横倾**；倾角超限 → 弃船倾覆；单舱进满不沉（多舱才会）。
- **物理沉没**（NavalArt 理念）：沉没是浮力/重心物理结果，不是血条清零——进水改变浮态，浮态驱动破口入水与倾覆，形成正反馈。

## WT 行为与证据

- 官方 wiki Ship Crew Mechanics / Ship Modules：舱室进满、浮力损失合计可 >100%、泵机制。
- 2017 官方《Naval Test: New aiming system, hydrodynamics》：单侧进水横倾、不修正则倾覆。
- 社区多帖截图横倾；2019 机制帖："水上破口记录、下沉后激活进水"。

## NavalArt 参考

体积排水浮力（排水体积 vs 总重定吃水）；V1.0（2024-11）波浪实时物理；1.53 加浮心(CoB)指示器与纵倾；容积泵。物理沉没是其表现灵魂，直接吸收。

## 历史变化

Leviathans 前后破口规则差异大（见 MDR-0007）；旧"不可修补破口"已废除。

## 未知点

进水流量公式（破口尺寸→m³/s）；泵排水速率；倾覆角阈值；舱容数值。

## 实现与替换方案

- Phase 3：`FloodingSystem`（破口集合、水下判定、流量∝破口面积、泵）+ `BuoyancySolver`（分段体积法：吃水/横倾/纵倾，接口预留高保真 CFD 级替换）。
- 全部流量/速率进 calibration（`approximation:true`）。
