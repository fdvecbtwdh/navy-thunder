# MDR-0013: 飞机伤害模型与击杀判定

- 状态: 已决议
- 置信度: **高**
- 参考优先级: War Thunder（战斗计算）

## 决议

**模块清单**：机身段、两侧机翼（翼根/翼中/翼尖分段+逐段翼梁）、尾翼/垂尾、控制面（副翼/升降舵/方向舵）、控制缆线、液压、起落架、散热器/油冷器、分段油箱（自封属性）、发动机、增压器/涡轮、螺旋桨、飞行员、弹药架。

**关键规则**：
- **翼梁**：受损后 "Critical G %" 上限下降；过载超限 → 断翼脱落 = **立即击毁**；外挂炸弹/火箭加权。
- **缆线断裂** → 对应舵面失去输入；液压损坏影响起落架与助力；控制面可单独打黑/打红。
- **油箱**：命中→漏油/漏燃料（拖尾暴露）→燃油火；自封油箱难被单发点燃；小油箱火可自熄（社区实测 ~3.3 分钟）；油箱爆炸=立即击毁。
- **发动机**：熄火（可空中重启）/功率下降/起火（可烧断结构）；散热器漏→渐进过热掉功率。
- **飞行员死亡 = 立即击毁**；弹药架殉爆 = 立即击毁。
- **损伤写回飞行模型**：翼面残缺→升力损失+诱导阻力上升；蒙皮洞→寄生阻力；丢部件/泄燃料→重量变化；发动机→推力衰减。这是"打黑翼根比打引擎更致命"手感的本质。
- **空对空弹丸级**：每颗弹丸独立结算；伤害=动能(½mv² 随存速)+炸药(爆炸)+破片锥(沿来袭 ±30–45°)；HE 引信三元判定（灵敏度/延迟/剩余穿深）→ 对薄结构过穿不炸。

**击杀判定**（官方 destroy_rules，2026-09 抓取）：
- 立即击毁集：飞行员死亡、机翼脱落、内部爆炸（油箱/弹药架）。
- **Severe Damage**（2024-02）：引擎全毁/全部操纵失效/机翼脱落 → 不可控状态，记 80% 击杀奖励，需补刀 "Finished Off"。
- 伤害分级 Critical > Serious > Simple（结算与助攻用）。
