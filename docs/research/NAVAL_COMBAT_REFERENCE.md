# 海战交战循环参考（跨游戏综合）

> 定位：一整场海战的**玩家体验循环**设计输入：发现 → 接敌 → 瞄准 → 开火 → 命中反馈 → 损管 → 终局。来源：WT 官方资料（W 系列，见 WAR_THUNDER_NAVAL_RESEARCH）、WT 社区观察（Level D/E）、NavalArt 反编译（NA 系列）、以及明确的 Level E 交叉参考（WoWS 等，标注处）。
> NT 现状列 = 2026-10-02 代码实测（Level A）。

## 1. 交战循环总览（目标态）

```
发现(目视/雷达) → 目标锁定(信息卡) → 接敌机动(占位)
   → 瞄准(测距→试射→修正) → 齐射(散布/弹种) → 观察水柱/命中反馈
   → 循环 …；受击侧：损伤面板 → 损管决策 → 机动规避
   → 终局：击沉(姿态/进水) → 战报
```

## 2. 逐环节三方对照

### 发现与锁定
- **WT**：目视+雷达修正；锁定目标出信息卡；装甲分析器有舰员密度热图（W1）。
- **NavalArt**：探测=精度修正（accuracyGain），无视野雾（NA §5）。
- **NT 现状**：无发现/锁定概念（全部实体可见，2D）。
- **NT 目标**：`DESIGN DECISION` 单机 PvE 保持全可见（不做战争迷雾——AI 与玩家对称、确定性渲染简单），锁定=目标管理 UI（Phase 05）；雷达作为精度/AA 弹幕修正器（MDR-0014 已裁决）。

### 接敌与机动
- **WT**：油门轴式+倒车；速度影响回转；机动降低双方精度（W7 官方原文——"任何机动都显著降低射击精度"）。
- **NT 现状**：油门 0-1 无档位无倒车；机动不影响精度。
- **NT 目标**：Phase 04 机动精度惩罚（进 GunSystem 散布项，对称作用于 AI）；倒车/档位 Phase 05。

### 瞄准（核心差异环节）
- **WT**：AB=自动测距带误差+三发试射锁定区间；RB=测距员读数+玩家看水柱手动修正（滚轮）；换目标重置（W7）。
- **NavalArt**：炮塔数据含散布/俯仰界/低伸-高拋双弹道（NA §5），玩家手动指哪打哪（无火控解算层）。
- **NT 现状**：无玩家瞄准（悬停自动交战）；`FcsSolver` 在库未接。
- **NT 目标**：`DESIGN DECISION` 两档火控（MDR-0014 已裁决）：自动档=锁定目标+试射修正循环（对齐 W7 AB 流程，FcsSolver 出提前量指示）；手动档=方向+距离手调（滚轮）。AI 炮手=自动档+难度误差。

### 开火与命中反馈
- **WT**：齐射散布 127-380mm +5-13%（W5）；hit icons 可开关（W4）；hit cam（浮性/隔舱/乘员%，W7）；水柱=主要弹着观察物。
- **NavalArt**：击穿/过穿/未穿/HE 四态反馈+伤害贴花（NA §6）。
- **NT 现状**：事件圆弧特效；无四态反馈图标。
- **NT 目标**：Phase 05 四态命中图标（数据已在 ProjectileArmorImpact.Outcome 里，FACT）。

### 损管决策
- **WT**：2.51 三流程自动+优先级+手动开关（W6）。
- **NT 现状**：全自动、无 UI。
- **NT 目标**：Phase 05 损管面板（优先级预设+模式开关），后端 `DamageControlSystem.Priority/Mode` 已存在（FACT：`DcMode.Automatic/Manual` + `Priority` 列表），**纯接线任务**。

### 终局
- **WT**：沉没姿态/倾覆视觉（W5 重新启用）；战报/得分。
- **NavalArt**：随机姿态+60s 倾侧脚本（NA §4，NT 不采纳随机性）。
- **NT 现状**：KillState+退水线（2D）。
- **NT 目标**：Phase 04 沉没姿态从损伤分布涌现（横倾/纵倾驱动）；Phase 02 沉没动画。

## 3. Level E 交叉参考（明确低可信，仅 UX 形状参考）

- **World of Warships**：锁定+提前量指示 UI 形状、损管消耗品（主动技能型）——消耗品模型**不采纳**（与 NT 模拟制冲突）；其 lead indicator 形状可作 Phase 05 参考。

## 4. 循环节奏数值锚点（供平衡参考）
